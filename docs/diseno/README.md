# Maquetas de referencia

Diseño aprobado de la versión modular (launchpad al estilo Fiori). Son archivos de un lienzo de diseño, no código de la
app: sirven como referencia visual al construir cada módulo.

| Archivo | Pantalla |
| --- | --- |
| `Main.dc.html` | Launchpad en escritorio |
| `LaunchpadMovil.dc.html` | Launchpad en celular |
| `VentaMovil.dc.html` | Nueva venta en celular (precio colegio / público) |
| `Inventario.dc.html` | Productos y stock |
| `Reposicion.dc.html` | Stock mínimo y reposición |
| `Dashboard.dc.html` | Ventas y stock real |
| `Modulos.dc.html` | Módulos activos y paquetes por rubro |

Los datos que muestran son de ejemplo.
